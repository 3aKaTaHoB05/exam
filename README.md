# Предметная область

Система учета прививок обеспечивает сбор, хранение информации о прививках в медицинских учреждениях, что упрощает работу медицинских сотрудников.

## Основные функции

* **Капча**: Создание капчи для отражения автоматизированнных атак;
* **Аунтификация**: Проверка логина и пароля.
